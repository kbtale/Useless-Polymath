# Security Policy

## Supported Versions

Useless Polymath is deployed continuously from `master`. Only the latest version receives security updates:

| Version | Supported |
| ------- | --------- |
| Latest (0.0.1) | Yes |

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

To report a vulnerability, create a private security advisory on GitHub at https://github.com/kbtale/Useless-Polymath/security/advisories, or email the maintainer directly at cbolivar.dev@openrise.tech.

Please include the following details in your report:

- A description of the vulnerability and its impact.
- Steps to reproduce the issue.
- The affected version and environment (browser, theme, language).

## Response Timeline

- Acknowledgment of the report within 48 hours.
- A fix for critical issues within 7 days.
- Regular status updates until the issue is resolved and disclosed.
